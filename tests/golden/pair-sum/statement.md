# Pair Sum

The first line holds `n` and a target `t`. The second line holds `n` integers
`a_1 … a_n`. Print two different positions `i` and `j` (1-based) with
`a_i + a_j = t`. At least one such pair exists. If there are several, print any of them.

## Constraints

- 2 ≤ n ≤ 10^5
- |a_i|, |t| ≤ 10^9

## Example

Input:

```
4 9
2 7 11 15
```

Output:

```
1 2
```
