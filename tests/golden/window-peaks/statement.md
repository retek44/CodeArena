# Window Peaks

A sensor gives `n` readings. Slide a window of `k` consecutive readings from the start to the
end, one step at a time, and print the largest reading in each window position, separated by
spaces, on one line.

The first line holds `n` and `k`. The second line holds the readings.

## Constraints

- 1 ≤ k ≤ n ≤ 10^5
- |reading| ≤ 10^9
