# Circle Area

Read the radius `r` of a circle and print its area.

Answers within an absolute or relative error of 10^-6 are accepted, so the number of
printed digits is up to you.

## Constraints

- 0 ≤ r ≤ 10^4, `r` may have a fractional part

## Example

Input:

```
1
```

Output:

```
3.141592653589793
```
