# Exact Change

A till has coins of `k` values and as many coins of each value as you like. Pay exactly `a`
with as few coins as possible and print how many coins you need, or `-1` if `a` cannot be
paid exactly.

The first line holds `k` and `a`. The second line holds the `k` coin values.

## Constraints

- 1 ≤ k ≤ 100
- 0 ≤ a ≤ 10^4
- 1 ≤ coin value ≤ 10^4
