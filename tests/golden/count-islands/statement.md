# Count Islands

A map is a grid of `r` rows and `c` columns: `#` is land and `.` is water. Land cells that
share a side belong to the same island; cells that only touch at a corner do not. Print the
number of islands.

The first line holds `r` and `c`. Then `r` lines follow with `c` characters each.

## Constraints

- 1 ≤ r, c ≤ 1000
