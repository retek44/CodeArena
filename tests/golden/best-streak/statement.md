# Best Streak

A shop writes down its profit for each of `n` days; a bad day has a negative profit. Find
the largest total profit over a run of consecutive days. The run has at least one day.

The first line holds `n`. The second line holds the profits `p_1 … p_n`. Print one
integer: the largest total.

## Constraints

- 1 ≤ n ≤ 10^5
- |p_i| ≤ 10^9
