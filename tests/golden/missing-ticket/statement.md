# Missing Ticket

Tickets numbered 1 to `n` were sold and one of them was lost. You get the numbers of the
other `n - 1` tickets in any order. Print the number of the lost ticket.

The first line holds `n`. The second line holds the `n - 1` numbers (it is empty when
`n` is 1).

## Constraints

- 1 ≤ n ≤ 10^5
